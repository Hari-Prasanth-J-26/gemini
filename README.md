# 🚀 Gemini — AI Chat Clone (React)

![Status](https://img.shields.io/badge/status-active-success)
![Build](https://img.shields.io/badge/build-Vite-orange)
![React](https://img.shields.io/badge/React-17.0.2-blue)

A modern **Gemini AI clone web application** built with **React.js** and **Vite**, featuring an interactive chat interface that replicates key elements of the Gemini AI experience. Users can interact with the UI to simulate conversational responses and explore a generative AI-style interface.

🌐 **Live Demo:** https://gemini-clone-webapp.netlify.app/

---

## 🧠 About the Project

This project recreates a **Gemini-like chat experience** using React and modern frontend tooling.  
It demonstrates:

* Responsive and dynamic chat UI
* Component-based React architecture
* API integration (if included) for conversational responses
* Rapid development with Vite

This serves as a frontend project that mimics features of a real conversational AI interface, ideal for portfolios and frontend demos.

## ⚙️ Getting Started

### Prerequisites

* Node.js (LTS recommended)  
* npm / yarn

---

### Installation

```bash
git clone https://github.com/Hari-Prasanth-J-26/gemini.git
cd gemini
npm install
```

---

### Run Locally

```bash
npm run dev
```

Then open in browser:

```
http://localhost:5173
```

## 🗂 Project Structure

```gemini/
├─ public/
│   ├─ index.html
│   └─ favicon.ico
├─ src/
│   ├─ components/
│   ├─ pages/
│   ├─ App.jsx
│   └─ main.jsx
├─ .gitignore
├─ package.json
├─ vite.config.js
└─ README.md
```

* `components/` → UI components blocks
* `pages/` → Screen-level pages
* `App.jsx/` → Main app wrapper
* `main.jsx/` → Entry point

## 🚢 Deployment

Or deploy manually using CLI.
